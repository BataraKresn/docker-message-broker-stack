# Support Policy

Terima kasih sudah menggunakan **docker-message-broker-stack**.

Dokumen ini menjelaskan kanal bantuan yang direkomendasikan agar komunikasi lebih tertib dan efektif.

## Kanal support

### 1) GitHub Discussions (direkomendasikan)

Gunakan untuk:

- tanya-jawab implementasi
- best practice deployment
- ide pengembangan dan feedback
- diskusi desain arsitektur

Link:

- https://github.com/BataraKresn/docker-message-broker-stack/discussions

### 2) GitHub Issues

Gunakan untuk:

- bug report terverifikasi
- feature request yang actionable

Link:

- https://github.com/BataraKresn/docker-message-broker-stack/issues

Mohon gunakan template issue yang tersedia.

### 3) Security report (jangan public issue)

Untuk kerentanan keamanan, **jangan** posting detail eksploit di issue public.

Silakan hubungi maintainer secara privat atau gunakan mekanisme private reporting jika tersedia.

## Scope support

Didukung:

- pertanyaan setup dev/prod sesuai dokumentasi repo
- troubleshooting komponen Redis/RabbitMQ/Kafka pada stack ini
- pertanyaan monitoring, backup/restore, dan hardening baseline

Di luar scope utama:

- debugging aplikasi bisnis spesifik di luar contoh repo
- tuning performa yang sangat khusus environment proprietary

## Ekspektasi respons

- Prioritas: bug production-impacting > bug umum > enhancement > pertanyaan umum
- Respons terbaik-effort (komunitas/open collaboration)
