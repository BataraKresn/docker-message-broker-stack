# Release Notes v1.0.0 (ID + EN)

Tanggal rilis / Release date: **2026-05-15**

---

## 🇮🇩 Bahasa Indonesia

Rilis ini adalah milestone awal `docker-message-broker-stack` dengan fokus pada kesiapan development dan production.

### 🎯 Highlight

- Stack broker lengkap: Redis, RabbitMQ, Kafka (KRaft)
- Mode dev cepat + mode prod lebih aman
- Monitoring built-in (Prometheus + Grafana + exporters)
- Contoh aplikasi producer/consumer multi-bahasa
- Dokumentasi dan runbook operasional lengkap

### ✅ Komponen yang tersedia

#### Redis

- Dev: single node + password
- Prod: master, replica, sentinel
- Script test: SET/GET, LPUSH/BRPOP, XADD/XREAD

#### RabbitMQ

- Dev: single node + management UI
- Prod: cluster 3 node + HAProxy TCP AMQP
- Definitions dan policy untuk DLX/retry queue

#### Kafka

- Dev: single node KRaft + Kafka UI
- Prod: cluster 3 broker/controller KRaft
- Default topics: `app-events`, `order-events`, `notification-events`, `audit-logs`

#### Monitoring

- Prometheus + Grafana
- Redis exporter
- Kafka exporter
- RabbitMQ prometheus metrics

### 🔐 Security baseline

- Redis dan Kafka tidak diekspos public by default
- Password/secret via env
- `no-new-privileges` untuk service terkait
- Rotasi log container
- Dokumentasi hardening firewall/TLS/secrets

### 🧪 Validasi pada rilis ini

- Lint compose:
  - dev compose
  - prod compose
  - prod + monitoring compose
- Healthcheck disiapkan untuk semua service utama

### 📌 Catatan operasional

- Untuk production, pastikan `.env.prod` berisi secret kuat non-default.
- Uji failover Redis Sentinel sebelum go-live.
- Verifikasi RabbitMQ cluster health dan Kafka quorum di environment target.

### 🔄 Upgrade/rollback

Karena ini rilis awal, tidak ada jalur migrasi dari versi sebelumnya.

## 🇬🇧 English

This release is the initial milestone of `docker-message-broker-stack`, focused on production-readiness while keeping developer experience simple.

### 🎯 Highlights

- Complete broker stack: Redis, RabbitMQ, Kafka (KRaft)
- Fast dev mode + safer production mode
- Built-in monitoring (Prometheus + Grafana + exporters)
- Multi-language producer/consumer examples
- Comprehensive documentation and operational runbooks

### ✅ Included components

#### Redis

- Dev: single node + password
- Prod: master, replica, sentinel
- Test scripts: SET/GET, LPUSH/BRPOP, XADD/XREAD

#### RabbitMQ

- Dev: single node + management UI
- Prod: 3-node cluster + HAProxy TCP AMQP
- Definitions and policies for DLX/retry queue

#### Kafka

- Dev: single-node KRaft + Kafka UI
- Prod: 3 broker/controller KRaft cluster
- Default topics: `app-events`, `order-events`, `notification-events`, `audit-logs`

#### Monitoring

- Prometheus + Grafana
- Redis exporter
- Kafka exporter
- RabbitMQ Prometheus metrics

### 🔐 Security baseline

- Redis and Kafka are not publicly exposed by default
- Passwords/secrets are env-driven
- `no-new-privileges` enabled for relevant services
- Container log rotation is configured
- Hardening docs available (firewall/TLS/secrets)

### 🧪 Validation in this release

- Compose lint validation for:
  - dev compose
  - prod compose
  - prod + monitoring compose
- Healthchecks are provided for all core services

### 📌 Operational notes

- For production, ensure `.env.prod` contains strong non-default secrets.
- Run Redis Sentinel failover tests before go-live.
- Verify RabbitMQ cluster health and Kafka quorum in target environments.

### 🔄 Upgrade/rollback

As this is the first release, there is no migration path from earlier versions.
