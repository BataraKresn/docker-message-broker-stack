# Release Notes v1.0.0

Tanggal rilis: **2026-05-15**

Rilis ini adalah milestone awal `docker-message-broker-stack` dengan fokus pada kesiapan penggunaan development maupun production.

## 🎯 Highlight

- Stack broker lengkap: Redis, RabbitMQ, Kafka (KRaft)
- Mode dev cepat + mode prod lebih aman
- Monitoring built-in (Prometheus + Grafana + exporters)
- Contoh aplikasi producer/consumer multi-bahasa
- Dokumentasi dan runbook operasional lengkap

## ✅ Komponen yang tersedia

### Redis

- Dev: single node + password
- Prod: master, replica, sentinel
- Script test: SET/GET, LPUSH/BRPOP, XADD/XREAD

### RabbitMQ

- Dev: single node + management UI
- Prod: cluster 3 node + HAProxy TCP AMQP
- Definitions dan policy untuk DLX/retry queue

### Kafka

- Dev: single node KRaft + Kafka UI
- Prod: cluster 3 broker/controller KRaft
- Default topics: `app-events`, `order-events`, `notification-events`, `audit-logs`

### Monitoring

- Prometheus + Grafana
- Redis exporter
- Kafka exporter
- RabbitMQ prometheus metrics

## 🔐 Security baseline

- Redis dan Kafka tidak diekspos public by default
- Password/secret via env
- no-new-privileges untuk service terkait
- Rotasi log container
- Dokumentasi hardening firewall/TLS/secrets

## 🧪 Validasi pada rilis ini

- Lint compose:
  - dev compose
  - prod compose
  - prod + monitoring compose
- Healthcheck disiapkan untuk semua service utama

## 📌 Catatan operasional

- Untuk production, pastikan `.env.prod` berisi secret kuat non-default.
- Uji failover Redis Sentinel sebelum go-live.
- Verifikasi RabbitMQ cluster health dan Kafka quorum di environment target.

## 🔄 Upgrade/rollback

Karena ini rilis awal, tidak ada jalur migrasi dari versi sebelumnya.
